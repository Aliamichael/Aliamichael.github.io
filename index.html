Research

Sender identification from the preamble of LoRa frames

M2 internship report · LIMOS (CNRS UMR 6158), Université Clermont Auvergne · Mar–Sep 2024
Supervised by Prof. Alexandre Guitton and Dr Nancy El Rachkidy

LoRaWAN frames carry a device identifier, which costs throughput on a network that only moves a few bits per second. I tested whether the gateway could instead recognise the sender from physical traits of the frame preamble: the carrier frequency offset (CFO) and symbol timing offset (STO).

  • Set up Heltec LoRa 32 end devices and a BladeRF software-defined radio gateway in GNU Radio, then built a simulator when hardware compatibility blocked capture.
  • Generated 2,000 frames from 20 nodes at spreading factor 8, with separate channel and per-gateway noise models grounded in the 868 MHz hardware limits.
  • Compared five supervised models and three clustering methods using one and two gateways.

Exploration with obstacles by luminous robots

M2 research project · LIMOS, Université Clermont Auvergne · SkyData project (ANR) · Oct 2023–Mar 2024
Supervised by Anaïs Durand · Project page

Swarms of very simple robots can explore a space together if they coordinate well. These luminous robots have no memory, a short sensing range and no shared sense of direction, and they communicate only by showing coloured lights to their neighbours. The goal is a distributed algorithm that explores a finite 2D grid perpetually, so that every node is visited infinitely often.

  • Studied grids that contain obstacles, a case the existing literature does not cover.
  • Analysed an optimal exploration algorithm by Bramas, Lafourcade and Devismes (ICDCN 2021) to test whether it still holds.
  • Showed that the algorithm still works with a single obstacle on an edge of the grid, but fails when the obstacle sits in a corner.

Identifying antibiotic-resistant bacteria using machine learning

MSc Data Science thesis · GITAM University · Dec 2022–Apr 2023
Supervised by Prof. T. Uma Devi

I encoded Neisseria gonorrhoeae genomes with BioPython, used unitigs (DNA sequences shared across strains) as features, and trained decision tree and support vector classifiers, with XGBoost explored, to predict resistance to azithromycin, ciprofloxacin and cefixime. Models were tuned with GridSearchCV and k-fold cross-validation and scored on balanced accuracy, precision, recall and F1.
